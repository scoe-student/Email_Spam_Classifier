The Email Spam Classifier is a machine learning-based application that automatically detects whether an email is spam or ham (not spam).
It uses natural language processing (NLP) techniques to analyze the text content of emails and classify them using trained machine learning models.

⚙️ Tech Stack

Programming Language: Python

Libraries Used: Pandas, NumPy, Scikit-learn, NLTK

Algorithms: Multinomial Naive Bayes, Logistic Regression (optional comparison)

IDE Used: Jupyter Notebook / VS Code

Dataset: Spam Collection Dataset (CSV/Text format)
